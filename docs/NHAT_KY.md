# Nhật ký thí nghiệm — vòng 3

Ghi **mọi** lần chạy vào đây, kể cả khi hỏng, kèm lý do hỏng. Một dòng tiêu đề, vài dòng số.

Mẫu:

```
## <ngày giờ> — <tên đòn>
Giả thuyết:   ...
Đối chứng:    <tag> (chỉ khác đúng cờ ...)
Ngưỡng đăng ký trước: phải ≥ +X điểm mới đi tiếp
Kết quả:      <tag> = <điểm>  vs đối chứng <điểm>   → Δ = ...
Kết luận:     nhận / loại / cần đo thêm
```
